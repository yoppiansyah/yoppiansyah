# About Me:
I’m currently working on building a task management app with Laravel and React, and automating backups to a personal cloud server.<br>
I’m looking to collaborate on open-source DevOps tools, homelab automation projects, or anything involving Kubernetes and self-hosting.<br>
I’m looking for help with optimizing Kubernetes + Rancher in resource-constrained environments and improving Godot game performance.<br>
I’m currently learning Rust and Zig for high-performance systems programming, plus Infrastructure as Code with Ansible and Packer.<br>
Ask me about full-stack development, self-hosted services (Bitwarden, Home Assistant, Pi-hole), or managing a diverse tech stack from Fortran to TypeScript.<br>
Fun fact: My homelab has more uptime than most production servers, and I believe a well-documented project is better than clever code.
